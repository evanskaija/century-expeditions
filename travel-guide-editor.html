Travel Guide Content Editor

Update descriptions, image paths, checklists, FAQs and official links. Changes are local until the exported content file is published.

Use an existing image path such as assets/guide-town.jpg, or upload a new compressed image through your hosting file manager first. Keep section IDs unchanged so navigation works.

Publish the downloaded travel-guide-content.json in the website’s root folder using your usual hosting upload or deployment workflow. Also download the local preview content and upload travel-guide-content.js beside it. Both downloads are generated automatically; no code editing is needed. Reload the guide after publishing to check the result.
